# 발굴 대기열 처리 지시문

어드민에서 `발굴 요청서 작성`을 누르면 **발굴 요청**이 `대기` 상태로 쌓입니다.
이 문서 아래쪽 **[지시문]** 부분을 통째로 복사해서, **크롬이 연결된 Claude 채팅창**에 붙여넣으면
그 요청을 집어가 검색하고 결과를 어드민에 다시 채워 넣습니다.

## 쓰는 순서

1. 어드민 → 인플루언서 발굴 → 키워드(하나 이상) + 최소 팔로워수 + 발굴 수 입력 → `발굴 요청서 작성`
2. 화면에 `발굴 요청` 카드가 `대기` 배지와 함께 뜨는지 확인
3. 크롬에 인스타그램이 로그인된 상태인지 확인
4. 어드민 화면의 `지시문 복사` 버튼을 눌러 Claude 채팅창에 붙여넣기
   (화면 지시문에는 이번 요청의 키워드·팔로워수가 이미 채워져 있습니다.
   아래 **[지시문]** 은 대기열에서 조건을 직접 읽게 하는 범용 버전입니다)
5. 끝나면 어드민 발굴 화면에서 결과 표를 확인 → 옮길 사람 체크 → `컨택 리스트로 옮기기`

> 결과를 어드민에 쓰는 것까지 자동화가 하므로, 중간에 사람이 옮겨 적을 일은 없습니다.
> 다만 **컨택 리스트로 옮기는 마지막 판단은 사람이** 합니다 — 자동화는 후보를 모아줄 뿐입니다.

## 미리 알아둘 것

- 인스타그램은 짧은 시간에 많은 프로필을 여는 것을 좋아하지 않습니다. 한 번에 10~20명 정도가 무난합니다.
- 소개글 링크까지 열어보므로 한 명당 시간이 더 걸립니다. 대신 소개글만 보던 때보다 후보가 많이 남습니다.
- 소개글에 이미 신호가 있으면 링크는 열지 않습니다. 링크는 소개글로 판단이 안 될 때만 엽니다.
- 로그인이 풀려 있거나 보안 확인 화면이 뜨면 자동화가 멈춥니다. 그때는 직접 로그인한 뒤 다시 시키면 됩니다.
- 자동화가 안 되는 날에는, 발굴 요청 카드의 붙여넣기 칸에 결과를 직접 넣고 `결과 저장`을 눌러도 똑같이 동작합니다.

## [지시문]

```
브리보 인플루언서 어드민의 발굴 대기열을 처리해줘.

1. https://lightenuf.github.io/Influencer-Marketing-Admin/discovery 를 연다.
   (로그인 화면이 뜨면 나에게 알려주고 멈춰줘)

2. '발굴 요청' 카드를 읽는다. 상태가 '대기'가 아니면 처리할 요청이 없는 것이니
   그렇게 알려주고 끝낸다. '대기'라면 카드에 적힌 다음 값을 기억한다.
   - 검색 키워드
   - 최소 팔로워수
   - 발굴 수

3. 인스타그램에서 그 키워드를 찾는다. 해시태그 검색만으로는 놓치는 글이 많으니,
   해시태그 · 계정 이름 · 게시물 본문 검색을 함께 쓴다.
   브랜드를 해시태그 없이 멘션만 한 글도 대상이다.

4. 찾은 게시물의 작성자 프로필에 들어가, 아래 두 가지를 모두 만족하는 계정을
   '발굴 수'만큼 모은다.
   (가) 팔로워가 '최소 팔로워수' 이상
   (나) 본인 계정에서 공동구매를 한다는 신호가 아래 셋 중 한 곳에만 있어도 된다
       - 프로필 소개글에 '공구' · '마켓' · '할인' · '공동구매' 또는 날짜(9/15 · 10월 5일 같은)
       - 소개글에 걸린 링크(인포크·리틀리·링크트리 등)를 열어보면 공구 일정이 있음
       - 그 사람 게시물 캡션에 공구 일정이 적혀 있음 (예: 9/17~9/23 오픈)

   소개글만 보고 판단하지 말고, 소개글에 신호가 없으면 링크를 꼭 열어본다.
   다른 사람 공구를 소개하는 글은 제외하고, 본인이 여는 공구인지 확인한다.
   프로필과 링크를 여는 속도는 사람이 보는 정도로 유지하고,
   보안 확인이나 로그인 화면이 뜨면 즉시 멈추고 알려줘.

5. 모은 결과를 한 줄에 한 명씩 이 형식으로 정리한다. 칸은 | 로 나눈다.
   @아이디 | 팔로워수 | 소개글 한 줄 | 공구를 한다고 본 근거

   근거는 어디서 봤는지까지 적는다. 예)
   @sample_kr | 4.2만 | 두 아이 엄마 · 건강식 기록 | 인포크 링크에 10/2 공구 일정
   @sample2_kr | 1.8만 | 홈카페 | 게시물 캡션에 9/17~9/23 마켓 오픈

   이미 연락한 계정인지는 어드민이 걸러내니, 찾은 것은 그대로 다 적는다.

6. 어드민 발굴 화면의 '발굴 요청' 카드 안 붙여넣기 칸에 5번 결과를 붙여넣고
   '결과 저장' 버튼을 누른다.

7. 몇 명을 찾았고 그중 '발굴 대상'이 몇 명인지 알려준다.
   조건에 못 미쳐 뺀 사람이 있으면 왜 뺐는지도 한 줄로 알려준다.
   컨택 리스트로 옮기는 것은 내가 직접 확인하고 할 테니, 옮기지는 말아줘.
```
